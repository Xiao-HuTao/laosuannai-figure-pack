1. 打开 [发布页面](https://github.com/Xiao-HuTao/laosuannai-figure-pack/releases/tag/v2.1.0-preview)。
2. 下载附件 **laosuannai-2.1.0-preview.zip**。
3. 在 Coopanion 形象管理界面导入 ZIP，无需先解压。
